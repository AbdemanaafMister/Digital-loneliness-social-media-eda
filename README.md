# Digital Loneliness and Social Media Usage Among Teenagers

## Project Overview

An Exploratory Data Analysis (EDA) project investigating the relationship between social media usage and teenage lifestyle and mental wellbeing indicators.

This project explores how daily social media usage is associated with sleep patterns, stress, anxiety, academic performance, physical activity, and depression indicators among teenagers.

## Objectives

- Analyse daily social media usage patterns among teenagers.
- Identify popular social media platforms.
- Explore relationships between screen time and sleep duration.
- Examine stress, anxiety, and addiction indicators.
- Investigate associations with academic performance and physical activity.
- Understand patterns between depression labels and lifestyle factors.
- Identify meaningful correlations through statistical analysis and visualisation.

## Dataset

The dataset was sourced from Kaggle.

**Dataset:** [Teenager Mental Health](https://www.kaggle.com/datasets/algozee/teenager-menthal-healy/discussion/691716)

The dataset includes variables such as:

- Age and Gender
- Daily Social Media Hours
- Platform Usage
- Sleep Hours
- Screen Time Before Sleep
- Academic Performance
- Physical Activity
- Social Interaction Level
- Stress and Anxiety Levels
- Addiction Level
- Depression Label

## Exploratory Data Analysis

The project covers the following analysis:

1. **Data Exploration:** Dataset structure, dimensions, data types, and statistical summaries.
2. **Data Quality Assessment:** Missing values and duplicate records.
3. **Descriptive Statistics:** Average age, screen time, sleep, stress, and other indicators.
4. **Social Media Usage:** Platform preferences and usage distribution.
5. **Sleep Analysis:** Sleep duration and screen time before bedtime.
6. **Mental Wellbeing:** Stress, anxiety, addiction, and depression indicators.
7. **Academic Performance:** Exploring associations with social media usage.
8. **Physical Activity:** Examining activity patterns in relation to digital usage.
9. **Correlation Analysis:** Correlation matrix and heatmap to identify relationships.

## Key Insights

- Average daily social media usage in the dataset is approximately 4.5 hours.
- Instagram and YouTube are among the most popular platforms.
- Sleep patterns show associations with social media usage and mental wellbeing indicators.
- Stress and anxiety levels vary across teenagers.
- Social media usage shows associations with academic performance and physical activity.
- Correlation analysis highlights relationships between lifestyle and mental wellbeing variables.

## Limitations

The dataset represents a cross-sectional snapshot.

Correlation does not establish causation.

Self-reported measurements may introduce bias.

The dataset may not represent all teenage populations.

Further longitudinal research would be needed to establish long-term relationships.

## Conclusion

This project highlights patterns between social media usage, lifestyle habits, and mental wellbeing among teenagers.

The analysis demonstrates the importance of understanding digital behaviour through data-driven insights rather than assuming direct cause-and-effect relationships.
